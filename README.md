# CyChat Runner

Python runners used by [CyChat](https://apps.cytoscape.org/apps/cychat). **CyChat automatically downloads the executable for your platform.** No manual installation is needed.

Supports Linux x86-64 (glibc 2.35+), Windows 10/11 x86-64, and macOS 12+ (Intel/Apple Silicon). CyChat provides the sandbox. Standalone downloads are unsigned and may trigger Gatekeeper or SmartScreen warnings.
